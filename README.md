# Thinking

个人知识库，记录前端、全栈、架构、与 AI Agent 的实践思考。

## 技术栈

- **Rspress** - 文档站点
- **Turbo** - monorepo 构建流水线
- **pnpm** - workspace 包管理
- **TypeScript** - 示例代码与工具脚本
- **D2** - 文档图表

## 常用命令

```bash
rtk pnpm test           # 运行全部测试（turbo）
rtk pnpm build          # 构建所有包（turbo）
rtk pnpm docs:dev       # 启动 Rspress 文档开发服务器
rtk pnpm docs:build     # 构建 Rspress 文档
```
